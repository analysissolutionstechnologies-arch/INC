Restriction of Journals for Users Odoo Apps

User Journal Restriction app helps users gain control over their journal access and usage. This app offers a wide range of features and functionalities, enabling organizations to enhance the security and efficiency of their financial management systems.

With this app, users gain the ability to customize access permissions and visibility settings for their journals. That ensures that financial data remains confidential and is only accessible to authorized staff members, maintaining the integrity of the organization's financial records. The user can make visible or use only the allowed journal in payment.

Features

Restrict Journal Access Rights

You have to enable or disable restrict journal features from user configuration.

Access Only Allowed Journals

You can visible or use only allowed journals.

Allowed Users in Journal

You can visible allowed users in specific journal.

Allowed Journal in Payment

You can only visible allowed journals in register payment.

Restrict Journal Access Rights

Under user configuration, You can enable "Access Rights for Restrict Journal" and "Restrict Journal Features" checkbox to restrict journals for that specific user.

Allowed Journals

You can select journals to allowed for that specific user.

Display Allowed Journals

You can see only allowed journals should be visible for that user.

Display Allowed Users

In journal form, You can view allowed users to access that specific journal.

Select Journal in Register Payment

User can see only allowed journal should be visible in register payment.

Select Journal in Payment

User can see only allowed journal should be visible in payment form.

Disable Restrict Journal Features

User can disable "Restrict Journal Features" checkbox to view all journal without any restriction.
