POS Sale Quantity Limit

This module is allow to set sale quantity limit on product and product category



App Features
  • Set sale quantity limit on product
  • Set sale quantity limit on product category
  • Restrict to sale products more than sales limit
  • Compatible with community and enterprise
POS Sale Quantity Limit

You can set sale quantity limit on products


Also you can set sale quantity limit on product category


You can restrict to sale quantity on more then limit on specific pos


When user click on payment button system will check the sale quantity limit on product or product category if sale quantity more then limit then system will restrict to validate order. Note : system will pick limit on product first if not then pick from product category.


System will restrict to sale product more then sale quantity limit set product or category
